1. Executive Summary

  • What it is: An automated multi-agent coordination system that manages apartment move-in and move-out operations across residents, landlords, and society administrators.
  • What it produces: 100% automated bylaw compliance checks, conflict-free service elevator holds with 15-minute lazy-TTL expiration, automated owner NOCs, and cryptographic digital gate passes.
  • How to try it right now: Run python -m uvicorn src.main:app --port 8000 and visit http://127.0.0.1:8000.

2. Problem & Solution

The Problem

Residential apartment communities experience severe operational friction on shifting days:

  • Moving trucks arrive during unpermitted hours or restricted Sundays.
  • Multiple moving crews fight over the single freight elevator.
  • Tenants vacate before clearing outstanding utility and maintenance dues.
  • Security guards block movers at the gate awaiting manual paperwork.

The Solution

PropAgent coordinates three specialized agents using the Model Context Protocol (MCP):

  • Tenant Agent automatically parses bylaws and holds the service elevator.
  • Owner Agent validates tenancy terms and checks zero-dues clearance.
  • Admin Agent signs off and issues a 6-digit OTP gate pass.
  • Security Terminal validates OTP and synchronizes society directory live.
